# books/

Учебные и справочные материалы.

## Клиническая психология — конспект лекций

`clinical_psychology_lectures.html` — краткий конспект из 20 лекций + шпаргалка для психологов: общая психопатология, шизофрения, аффективные, тревожные и стресс-связанные расстройства, личность, психосоматика, зависимости, РПП, нейропсихология и деменции, суицидология, диагностика, психофармакология и психотерапия, нейроразвитические расстройства (детско-подростковая клиника), тяжёлая болезнь/паллиатив/горевание, расстройства сна. Коды выверены по ICD-11 CDDR (ВОЗ).

- Уровень: профессиональный (для психологов), без вводной «воды».
- Формат: тезисы, определительные словари, таблицы диффдиагнозов, «красные флаги».
- Навигация: боковое меню с фильтром, переходы «←/→» между лекциями, горячие клавиши (стрелки, M — меню), печатная версия разворачивает все лекции.
- Один автономный HTML-файл, работает офлайн.
- В конце каждой лекции — интерактивный мини-тест (4 вопроса) с мгновенной проверкой и подсчётом результата «с первой попытки»; в книге по ST/ACT — тоже (16 тестов).

## Схема-терапия и ACT — конспект лекций

`schema_therapy_and_act_lectures.html` — 16 лекций + шпаргалка по современным доказательным методам: контекст третьей волны, схема-терапия Янга (18 схем, режимы, рескриптинг, ограниченное материнство, работа с расстройствами личности), ACT Хайеса (гексафлекс, дефузия, принятие, ценности), сравнение и интеграция методов, доказательная база. Тот же формат и навигация, что у первой книги.


## ВДА · рабочая тетрадь (2 версии)

- `wda_12_steps_workbook.html` — версия для психолога: шаги 1–3 подробно + каркас 4–12, вопросы включают профессиональную рефлексию.
- `wda_12_steps_client_workbook.html` — версия для клиента: тот же путь простым языком, без профессиональных вопросов; в каждом шаге поле «для встречи с психологом». Ответы хранятся только в браузере пользователя, экспорт — текстовым файлом.
