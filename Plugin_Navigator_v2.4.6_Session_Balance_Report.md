# Plugin Navigator 2.4.6 — сессия: баланс и главный элемент

## Фейдеры и панорама

Один базовый пункт, внутри два блока.

Фейдеры: inserts off → лидер на удобной громкости → опора → остальное опускать → слушать целиком.  
Панорама: место, не ширина; центр (вокал/kick/бас/snare); пары в стороны только при маскировке; проверка в mono.

## Главный элемент

В пункте «Послушать» — поле выбора источника. Кнопка ведёт в подбор цепочки для него. Хранится в `pn-session-lead`.

## Короткие уточнения

- Фаза: Polarity — не сдвиг клипа.
- Headroom: ориентир −12…−6 dBFS, не клиповать дорожки.
- Референс: те же мониторы и тихая громкость.
- Mono: проверить снова после фейдеров и панорамы.
