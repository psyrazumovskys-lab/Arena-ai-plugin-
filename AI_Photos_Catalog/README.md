# AI Photos Catalog — каталог фото, обработанных с помощью ИИ

Этот раздел хранит фотографии, обработанные нейросетями (апскейл, ретушь,
стилизация, генерация фона и т.п.).

## Структура

| Папка | Что хранить |
|---|---|
| `processed/` | Готовые фото после ИИ-обработки — основной каталог |
| `originals/` | Исходники до обработки (по желанию, для сравнения «до / после») |

## Правила именования файлов

Чтобы каталог оставался понятным, называйте файлы так:

```
ГГГГ-ММ-ДД_короткое-описание_модель-ии.расширение
```

Примеры:

- `2026-09-15_portret-studiya_midjourney.png`
- `2026-09-15_peyzazh-zakat_topaz-upscale.jpg`
- `2026-09-16_predmetka-na-belom-fone_photoshop-ai.jpg`

## Рекомендации

- Храните в `processed/` только финальные версии.
- Если у фото есть исходник — кладите его в `originals/` с тем же именем.
- Большие RAW-файлы и архивы сюда не кладите, только готовые JPG/PNG/WebP.
