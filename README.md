# Тетрадь практики

Краткая документация по консультациям + супервизорская обратная связь.

Здесь лежит **логика**: формат, шаблоны, инструкции. Клинических данных здесь нет и не должно появляться.
Данные — записи, тетради клиентов, разборы — живут на Google Диске.

## Как это устроено

Три уровня обратной связи, с разной ценой и разным смыслом:

| Уровень | Когда | Объём | Что даёт |
|---|---|---|---|
| **Отклик** | сразу после записи | 3–5 строк | одно наблюдение, один вопрос; при риске — сигнал наверх |
| **Разбор** | по запросу или раз в неделю | одна страница | динамика через встречи, статус гипотез, что обходится |
| **Неделя** | раз в неделю | полстраницы | кто двигается, кто застрял, где я устал, три приоритета |

Отклик после каждой сессии — сознательно дешёвый. Одна встреча почти ничего не доказывает, и разбор по одному эпизоду быстро превращается в уверенные банальности. Ценность накапливается в разборе и в недельном обзоре, где видно паттерн.

## Что где лежит

```
Google Диск
└── Практика/
    ├── _индекс.md              все клиенты, строка на каждого
    ├── _неделя/2026-W42.md     недельные обзоры
    ├── _входящие/              сырой текст с телефона — ваш
    └── К-07/
        ├── _тетрадь.md         сводка: запрос, формулировка, динамика, риски
        ├── 2026-10-14_05.md    встреча: запись + отклик + разбор
        └── 2026-10-07_04.md

Репозиторий (этот)
├── format.md                   спецификация формата
├── prompts/                    инструкции: запись, отклик, разбор, неделя
├── templates/                  пустые шаблоны
└── examples/                   заполненный вымышленный пример
```

## Правила

1. **В файлах только коды клиентов.** `К-07`, никогда имя. Ключ соответствия — в менеджере паролей, вне Диска, и в модель он не попадает.
2. **Запись не переписывается.** Слова терапевта остаются как есть. Разбор дописывается ниже, но не правит запись. Иначе через полгода невозможно восстановить, что было на самом деле.
3. **Риск — наверх.** Суицид, насилие, психоз, этический конфликт: в начало файла и дублируется в чат. Не хоронится в конце.
4. **Инбокс — ваш, остальное — моё.** Правки в тетради и индексе идут через меня, чтобы не было двух версий правды.
5. **Всегда видно, что прочитано.** Разбор начинается с перечня файлов и дат. Если прочитаны три встречи из десяти — это сказано.
6. **Наблюдение, гипотеза и вопрос различаются явно.** Догадка, прочитанная через месяц как факт, — главный способ испортить супервизию.
7. **Ссылок «поделиться» в папке практики не создаётся.** Доступ только по email.

## Как это работает в чате

- «К-07, встреча 6, [текст как помню]» → запись, отклик, обновление тетради и индекса.
- «Разбор по К-07» → супервизия по накопленному, с записью в файл.
- «Неделя» → обзор по всем клиентам.
- «Разбери инбокс» → превратить сырые заметки в записи.
