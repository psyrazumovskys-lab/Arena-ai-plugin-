# Plugin Navigator

Автономный русскоязычный справочник по аудиоплагинам и конструктор цепочек обработки.

**Актуальная версия: 2.7.6** — 17 октября 2026.

## Структура папки

- `current/` — актуальная версия: HTML-приложение, Windows x64, инструкция пользователя, видеоинструкция, контрольные суммы;
- `versions/` — архивные версии 2.4.0–2.6.1 (HTML, Windows-сборки, Download-архивы);
- `reports/` — отчёты и аудиты по всем версиям;
- `source/` — исходники, база данных, скрипты сборки и тесты.

## Готовые файлы (папка `current/`)

- `Plugin_Navigator_v2.7.0_Download.zip` — общий архив: HTML + Windows x64 + инструкции;
- `Plugin_Navigator_Full.html` — актуальное автономное HTML-приложение;
- `Plugin_Navigator_Full_v2.7.0.html` — версия с номером выпуска;
- `Plugin_Navigator_Full_v2.7.0_Windows_x64.zip` — portable Windows 10/11 x64;
- `Plugin_Navigator_User_Guide_RU.html` — инструкция пользователя в формате HTML;
- `Plugin_Navigator_User_Guide_RU.md` — исходный текст инструкции;
- `Plugin_Navigator_2.6.1_Video_Instruction_RU_*` — видеоинструкция (mp4 + srt);
- `CHECKSUMS_SHA256.txt` — контрольные суммы.

HTML-справочник работает без установки и интернета. Windows-версия полная, без Trial и ключей. Для неё требуется Microsoft Edge WebView2 Runtime, обычно уже установленный в Windows 10/11. EXE не подписан коммерческим сертификатом, поэтому SmartScreen может показать предупреждение.

## Новое в 2.7.6 — массовая отметка «Мои плагины»

Отмечать 365 плагинов по одному не нужно:

- **«＋ Все»** — отметить весь каталог одним нажатием (с подтверждением);
- **«＋ Отфильтрованные»** — отметка всех плагинов текущего фильтра/поиска (появляется, когда фильтр активен);
- **«Импорт списка»** — вставьте список плагинов из менеджера DAW (строками или через запятую): программа сопоставит имена с каталогом с устойчивостью к неточным написаниям, отметит совпавшие и покажет нераспознанные; есть режим «Заменить коллекцию списком» и полный сброс меток.

ИИ сразу учитывает массу: блок «ПЛАГИНЫ ПОЛЬЗОВАТЕЛЯ» в контексте и правило 11 работают одинаково для одного плагина и для всех 365.

## Новое в 2.7.5 — «Мои плагины» и честные ответы «у меня есть»

Исправлена слепота ИИ к коллекции пользователя: раньше программа не знала, какие плагины у вас установлены, и на вопрос «какие эквалайзеры у меня есть» модель отвечала общими советами.

- **отметка «У меня есть»** в карточке каждого плагина (рядом с личной заметкой) + бейдж «У МЕНЯ ЕСТЬ»;
- кнопка **«Только мои»** в каталоге — фильтр по отмеченным;
- список хранится локально (`pn-owned`) и входит в экспорт/импорт резервной копии;
- ИИ получает список вашей коллекции и по правилу 11 системного промпта отвечает на «какие у меня есть / из моих» **только** по нему; если список пуст — прямо говорит об этом и предлагает отметить плагины;
- для вопросов по типам («какие эквалайзеры имитируют аналоговый звук») в контекст передаётся **вся категория целиком** (например, все 5 семейств EQ с краткими описаниями) — модель фильтрует реальные записи каталога, а не вспоминает из общих знаний;
- лимит контекста поднят до 8000 символов; ретривал дополнительно бустит отмеченные плагины, когда вопрос содержит «мои/у меня».

## Новое в 2.7.4 — ИИ-панель на всех экранах

ИИ больше не привязан к своему разделу: в правом нижнем углу любого экрана появилась кнопка **«✦ ИИ-помощник»**, открывающая плавающую панель чата (сворачивается обратно в один клик, состояние запоминается).

- работает из любой вкладки: каталог, карточка плагина, конструктор, сравнение, глоссарий;
- ИИ получает контекст экрана: открытый раздел, открытую карточку плагина и список сравнения;
- быстрые кнопки панели зависят от экрана: на карточке — «объясни этот плагин», в конструкторе — «объясни текущую цепочку»;
- история чата общая с полным разделом ИИ; кнопка «⚙» ведёт в раздел управления движками и моделями;
- все предохранители сохранены: строгий контекст, подтверждение изменений цепочки, авторитет Помощника порядка.

## Новое в 2.7.3 — действия ИИ: цепочки, варианты, анализ настроек

ИИ перестал быть только «отвечающим» — теперь он может предлагать изменения, но финальное слово всегда за вами:

- **составление цепочек**: попросите «составь минимальную цепочку для Lead Vocal» — ИИ соберёт цепочку из плагинов локальной базы, и в чате появится карточка «Предложение ИИ · требует подтверждения» с этапами, маршрутами, Starting Settings и пояснениями. Кнопки «Применить цепочку» / «Отклонить»; ничего не применяется автоматически;
- **изменение текущей цепочки**: режимы «заменить» и «добавить этапы», с подтверждением, если цепочка не пуста;
- **варианты**: по запросу ИИ описывает несколько вариантов (A/B/C) и прикладывает действие для рекомендуемого;
- **анализ настроек**: разбор Controls по этапам — назначение, что проверить на слух, риски; исправления предлагаются через то же подтверждаемое действие;
- **контроль качества сохранён**: в запрос передаются доступные этапы выбранного источника и подходящие карточки; имена не из каталога игнорируются; после применения порядок и routing проверяет детерминированный Помощник порядка — он по-прежнему авторитетнее модели;
- в оба движка (WebLLM и Ollama) передан один и тот же протокол действий; для Ollama контекст поднят до 8192 токенов.

## Новое в 2.7.2 — загрузка модели Ollama из приложения

Модель для Ollama теперь можно скачать, не выходя из программы: в карточке Ollama появились кнопки рекомендованных моделей (`qwen3.5:2b-q4_K_M` ≈1,9 ГБ — для видеокарт с 3 ГБ памяти; `qwen3.5:4b` ≈3,4 ГБ — точнее), поле для произвольного имени из библиотеки ollama.com/library, индикатор прогресса и кнопка остановки. По окончании загрузки модель автоматически выбирается. Веса хранит Ollama; Plugin Navigator ничего не скачивает в свои папки.

## Новое в 2.7.1 — подключение Ollama

Если на компьютере установлен [Ollama](https://ollama.com), раздел ИИ может работать через него вместо встроенной WebLLM-модели:

- в разделе ИИ появился выбор движка: «Встроенный Qwen3.5 2B · WebLLM» или «Ollama на этом компьютере»;
- программа сама находит сервер Ollama по адресу `http://127.0.0.1:11434` и показывает список установленных моделей;
- подходит любая модель из библиотеки Ollama; для русского языка рекомендуется семейство Qwen;
- ответы стримятся построчно; сохраняется тот же строгий retrieval-контекст (до 5 карточек + текущая цепочка + результат Помощника порядка) и те же правила provenance;
- выбранный движок и модель запоминаются локально;
- встроенная WebLLM-модель 2.7.0 остаётся доступной без изменений — Ollama это опция, а не замена.

Ollama должен быть запущен (`ollama serve` или приложение Ollama). Обычная настройка `OLLAMA_ORIGINS` не требуется: запросы идут с localhost. Если доступ блокируется, запустите Ollama с переменной `OLLAMA_ORIGINS=*`.

## Новое в 2.7.0 — локальный ИИ

В Windows-приложение встроен движок **WebLLM 0.2.84** и интерфейс для одной модели:

```text
Qwen3.5 2B Q4
Qwen3.5-2B-q4f16_1-MLC
```

- облачный сервер, API-ключ, Python, Ollama и CUDA не требуются;
- модель загружается кнопкой внутри программы один раз, объём — около 1,1 ГБ;
- после загрузки она хранится в локальном WebView2 cache и формирует ответы офлайн;
- модель можно удалить из того же раздела;
- ИИ объясняет текущую цепочку, порядок, Controls и Starting Settings;
- в запрос передаются только подходящие карточки локального каталога и текущая цепочка;
- ответы ИИ помечены как практические рекомендации, а не официальные факты;
- строгий Помощник порядка остаётся авторитетнее модели;
- без WebGPU весь обычный справочник продолжает работать без ограничений.

Рекомендуется Windows 10/11, 16 ГБ RAM и актуальные WebView2/драйвер видеокарты. Минимально — 8 ГБ RAM и примерно 2,3 ГБ доступной GPU/shared memory.

## Сборка и проверка

Все команды выполняются из папки `source/`. Готовые файлы пишутся в `current/`, отчёты — в `reports/`.

Сборка HTML:

```bash
cd source
python3 -m pip install -r requirements.txt
python3 build_plugin_navigator.py
```

Полная проверка (сборка + все аудиты):

```bash
cd source
npm ci          # один раз, для UI-теста (нужен Node.js)
python3 build_and_test.py
```

Дополнительная проверка реальной вёрстки Chromium:

```bash
cd source/test-runtime
npx playwright install chromium
npm run test:browser
```

Сборка Windows:

```bash
cd source/Plugin_Navigator_Windows_Source
npm ci
cd ..
python3 build_windows.py
```

Скрипт берёт Neutralinojs x64 shell из предыдущего Windows ZIP (ищет в `current/` и `versions/`), обновляет Windows-версию файла, встраивает актуальный HTML, WebLLM runtime и AI Worker, затем извлекает и проверяет все встроенные ресурсы. Результат кладёт в `current/` вместе с обновлённым `CHECKSUMS_SHA256.txt`.
