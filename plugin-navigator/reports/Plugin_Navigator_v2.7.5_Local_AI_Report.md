# Plugin Navigator 2.7.5 — «Мои плагины» и честные ответы «у меня есть»

**Дата:** 17 октября 2026
**Статус:** реализовано в исходниках, детерминированной сборке HTML и Windows-релизе; живая проверка — на целевой машине.

## Мотивация (баг-репорт пользователя)

Вопрос «какие эквалайзеры, которые у меня есть, имитируют аналоговый звук» ИИ ответил общими рекомендациями, часть из которых у пользователя уже установлена. Диагноз подтвердился на коде:

1. **Программа не знала коллекцию пользователя.** В данных приложения есть каталог (365 справочных записей), избранное и текущая цепочка — но нет списка «какие плагины у меня установлены». ИИ физически не мог отфильтровать «мои».
2. **Ретривал передаёт только 5 карточек.** Для вопросов по типу («какие эквалайзеры…») этого мало: в базе 5 семейств EQ (~32 плагина: API, Neve, Pultec, linear-phase, parametric/dynamic) — модель видела пятёрку и дорисовывала остальное из своих общих знаний.

## Что сделано

### 1. «Мои плагины» — владение плагинами

- кнопка **«Отметить „у меня есть"»** / **«✓ У меня есть»** в карточке плагина (блок «Личная заметка»);
- бейдж **«У МЕНЯ ЕСТЬ»** в шапке карточки;
- кнопка **«Только мои · N»** в каталоге — фильтр `ownedOnly` в `filtered()`;
- хранение: `pn-owned` (localStorage), входит в экспорт/импорт резервной копии;
- быстрая кнопка ИИ-панели «Какие из моих отмеченных плагинов подойдут…».

### 2. Контекст ИИ

- блок **«ПЛАГИНЫ ПОЛЬЗОВАТЕЛЯ»**: список отмеченных (до 80 имён) с явным указанием «отвечай ТОЛЬКО из этого списка»; если пуст — инструкция честно сказать об этом и предложить отметить плагины, не выдумывая коллекцию;
- блок **«ВСЕ ПЛАГИНЫ КАТЕГОРИИ»** (`aiCategoryContext`): при упоминании в вопросе категории (сопоставление по словам русских названий категорий + спец-правила «эквалайзер→EQ», «компрессор→Динамика») в контекст попадает вся категория целиком, сгруппированная по семействам, с кратким описанием каждого плагина (имя, разработчик, kind; лимит 3800 символов на блок);
- правило 11 системного промпта: «какие у меня есть / из моих» → фильтровать только коллекцию пользователя; «ВСЕ ПЛАГИНЫ КАТЕГОРИИ» — каталог, не коллекция; не смешивать и явно указывать, чем отвечаешь; новое предлагать только по прямому запросу;
- ретривал: буст +40 для отмеченных плагинов, когда вопрос содержит «мои/моих/мою/моя/у меня»;
- общий лимит контекста 6800 → 8000 символов.

### Пример исправленного поведения

«Какие эквалайзеры, которые у меня есть, имитируют аналоговый звук?» → в контексте: вся категория «EQ и tone shaping» (5 семейств, все плагины с описаниями) + список «ПЛАГИНЫ ПОЛЬЗОВАТЕЛЯ» → модель фильтрует отмеченные пользователем плагины по аналоговому характеру (семейства API/Neve/Pultec и описания kind) и отвечает только по коллекции. Если ничего не отмечено — прямо сообщает об этом и предлагает кнопку «У меня есть».
