# Plugin Navigator 2.8.4 — воронка «вся категория → уточнения»

**Дата:** 18 октября 2026
**Статус:** реализовано в исходниках, детерминированной сборке HTML и Windows-релизе; живая проверка — на целевой машине.

## Мотивация

Пользователь попросил: ИИ должен уметь сначала выдать, например, все эквалайзеры каталога, а затем сокращать список в зависимости от уточнений — и так с любым типом плагинов.

## Что сделано

**1. Правило 13 «ВОРОНКА ПО КАТЕГОРИИ» в системном промпте.** «Покажи все эквалайзеры / ревербераторы / компрессоры» — ИИ перечисляет всю категорию из блока «ВСЕ ПЛАГИНЫ КАТЕГОРИИ» по семействам (имя — разработчик); если блок обрезан лимитом контекста — честно говорит, что показана часть. Последующие уточнения («только аналоговые», «для вокала», «убери это семейство») сужают предыдущий список с указанием, сколько осталось; плагины вне категории не добавляются, пока не попросят. Правило 12 (короткий запрос → 2–4 варианта) сохраняется: формат ответа выбирается по формулировке.

**2. Память категории между сообщениями.** Раньше категорийный контекст строился только по текущему вопросу: на уточнении «только аналоговые» слова «эквалайзеры» уже нет — блок категории пропадал, и модель не могла сужать список. Теперь `aiBuildContext` при отсутствии категории в вопросе анализирует предыдущий ответ ассистента: если в нём названо ≥5 плагинов одной категории, в контекст добавляется блок «КАТЕГОРИЯ ИЗ ПРЕДЫДУЩЕГО ОТВЕТА» с полным списком этой категории и пометкой «сужай, а не составляй заново».

**3. Распознавание всех категорий.** Два частных случая («эквалайз» → EQ, «компресс» → Dynamics) заменены функцией `aiCatBoost` со словарём ключевых слов для всех 13 категорий: реверберация, delay/эхо, сатурация/лампа/лента, гитарные усилители, модуляция/chorus/flanger/phaser, шум/очистка/деэссер, channel strips/консоли, low-end/сабвуфер, metering/loudness, инструменты/synth, лимитеры.

**4. Кнопка «▣ Показать в каталоге» — до 50 плагинов** (было 12): ответ «все эквалайзеры» (44 шт.) целиком отображается карточками в каталоге.
