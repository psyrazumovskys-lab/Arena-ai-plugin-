# Plugin Navigator 2.4.4 — учебная сессия

## Что изменилось

Экран «Сессия — до плагинов» остаётся чеклистом, но каждый из 7 пунктов теперь короткий урок.

Порядок сверху: послушать → прибрать → фаза → фейдеры → headroom → референс → mono.

У каждого пункта:

- зачем;
- что сделать (2–4 действия);
- что слушать;
- типичная ошибка;
- когда пропустить;
- как понять, что готово.

## База и условные

База (нужна галочка, skip не открывает переход):

1. Понял песню и кто главный
2. Клипы прибраны
3. Картина держится на фейдерах и панораме
4. Есть headroom

Условные (можно «Не нужно»):

- Фаза / polarity
- Референс
- Mono

На главном экране виден прогресс: «База N из 4».
