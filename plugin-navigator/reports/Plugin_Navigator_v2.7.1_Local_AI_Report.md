# Plugin Navigator 2.7.1 — Ollama-коннектор

**Дата:** 17 октября 2026
**Статус:** реализовано в исходниках и детерминированной сборке HTML; живая проверка с запущенным Ollama — на целевой машине (Xeon E5-2666 v3, GTX 1060 3 ГБ).

## Мотивация

Аудит железа (см. `Plugin_Navigator_AI_Engine_Choice_2026-10-17.md`) показал: встроенная модель 2.7.0 (Qwen3.5-2B-q4f16_1, WebLLM) на GTX 1060 3 ГБ находится в зоне риска — 2245 МБ из ~2500–2800 МБ доступного бюджета VRAM плюс медленная FP16-арифметика Pascal. Ollama официально поддерживает GTX 1060 (compute capability 6.1, драйвер 570+), использует FP32-путь Vulkan/CUDA и сама разгружает слои в RAM при нехватке VRAM. Это самый надёжный способ получить локальный ИИ на этой машине без замены железа.

## Что сделано

В раздел ИИ добавлен выбор движка (state `aiBackend`, persisted как `pn-ai-backend`):

- **Встроенный Qwen3.5 2B · WebLLM** — прежний путь 2.7.0 без изменений;
- **Ollama на этом компьютере** — новый коннектор.

Новые функции в шаблоне (`build_plugin_navigator.py`):

| Функция | Назначение |
|---|---|
| `aiOllamaPing` | `GET /api/tags` с таймаутом 2,5 с; заполняет список моделей, выбирает рекомендованную |
| `aiOllamaPickModel` | приоритет: `qwen3.5:4b` → `qwen3.5:2b` → `qwen3:4b` → … → первая qwen-модель |
| `aiOllamaChat` | `POST /api/chat` со стримингом (NDJSON), `num_predict:600`, `temperature:.25` |
| `aiOllamaError` | дружелюбные ошибки: сервер не запущен, модель не скачана, блокировка CORS |
| `aiOllamaPersist` | сохранение выбора движка и модели (`pn-ai-backend`, `pn-ai-ollama-model`) |

Изменены `aiSend` (маршрутизация по движку), `aiStop` (AbortController для Ollama), `aiView` (селектор движка + карточка Ollama с выбором модели и адресом сервера), `attachAI` (обработчики), `aiUpdateDOM` (guard для режима Ollama).

## Что сохранено

- тот же строгий system prompt с правилами provenance («Не выдумывай Controls», Product-specific/Product-informed/Family-level и т.д.);
- тот же retrieval: до 5 релевантных карточек + текущая цепочка + детерминированная проверка порядка (лимит контекста 5800 символов);
- Помощник порядка остаётся авторитетнее модели;
- stripping `<think>…</think>` через `aiVisibleText` (работает и для размышляющих моделей Ollama);
- история диалога (последний обмен) передаётся так же, как в WebLLM-пути.

## Инструкция для пользователя

1. Установить и запустить Ollama (приложение или `ollama serve`).
2. Скачать модель: `ollama pull qwen3.5:2b` (≈1,3 ГБ, целиком в VRAM 1060) или `qwen3.5:4b` (≈2,5 ГБ, часть слоёв уйдёт в RAM — медленнее, но заметно умнее).
3. В Plugin Navigator: раздел ИИ → «Движок локального ИИ» → «Ollama на этом компьютере» → «Проверить соединение» → выбрать модель.
4. Задавать вопросы как раньше.

CORS: Ollama по умолчанию разрешает запросы с localhost/127.0.0.1 на любом порту и со схем `file://`, `app://`. Windows-приложение (Neutralino, `http://localhost:49491`) и HTML-справочник открываются без дополнительных настроек. Если запрос блокируется — запустить Ollama с `OLLAMA_ORIGINS=*`.

Не пройдено в Arena (нет GPU/WebView2/самого Ollama):

- живой ping `/api/tags` из приложения;
- живой стриминг ответа `/api/chat`;
- поведение на GTX 1060 3 ГБ (скорости `qwen3.5:2b`/`4b`).

Чек-лист живой проверки на целевой машине:

1. `ollama list` — есть ли модели; при отсутствии: `ollama pull qwen3.5:2b`;
2. открыть раздел ИИ → переключить движок на Ollama → «Проверить соединение»;
3. убедиться, что в списке появилась модель и статус «Соединение установлено»;
4. задать тестовый вопрос («Объясни мою текущую цепочку»);
5. замерить скорость ответа (ожидание: 2B — десятки ток/с; 4B — ~10–20 ток/с);
6. проверить кнопку «Остановить» во время генерации;
7. перезапустить приложение — выбор движка и модели должен сохраниться.

## Рекомендации по моделям для этой машины

| Модель | VRAM Q4 | Ожидание на GTX 1060 3 ГБ | Комментарий |
|---|---|---|---|
| `qwen3.5:2b` | ~1,3 ГБ | десятки ток/с | умещается целиком, быстрый ответ |
| `qwen3.5:4b` | ~2,5 ГБ | ~10–20 ток/с | заметно умнее, частичная разгрузка в RAM |
| `qwen3.5:9b`+ | ~5+ ГБ | 3–7 ток/с | гибрид GPU+CPU, медленно; лучше не надо |
| встроенная WebLLM 2B | 2245 МБ | неизвестно до живого теста | q4f16 — риск на Pascal (FP16 1/64 скорости) |
