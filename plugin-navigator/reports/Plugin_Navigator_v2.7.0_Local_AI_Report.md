# Plugin Navigator 2.7.0 — локальный ИИ без сервера

**Дата:** 21 августа 2026  
**Статус:** реализовано и собрано; аппаратный запуск модели требует финальной проверки на Windows с WebGPU.

## Выбранная модель

```text
Qwen3.5 2B Q4
Qwen3.5-2B-q4f16_1-MLC
```

Причины выбора:

- компактная модель на 2B параметров;
- поддержка русского и других языков;
- готовая q4f16_1-сборка входит в официальный список моделей WebLLM 0.2.84;
- ориентировочный объём весов — 1,1 ГБ;
- заявленное WebLLM требование — около 2245 МБ GPU/shared memory;
- модель работает в браузерном WebGPU без API-ключа и облачного inference-сервера.

Официальные/технические источники:

- Qwen3.5 2B: https://huggingface.co/Qwen/Qwen3.5-2B
- MLC weights: https://huggingface.co/mlc-ai/Qwen3.5-2B-q4f16_1-MLC
- WebLLM: https://github.com/mlc-ai/web-llm

## Что встроено в программу

В Windows EXE находятся:

- весь основной Plugin Navigator;
- WebLLM 0.2.84;
- отдельный AI Web Worker;
- интерфейс установки, запуска, остановки и удаления модели;
- локальный retrieval по каталогу;
- строгий system prompt с правилами provenance.

Сами веса Qwen не вшиты в ZIP. Иначе каждый выпуск увеличился бы более чем на 1 ГБ и стал бы ненадёжным для GitHub-загрузок. Пользователь загружает веса один раз кнопкой в приложении. После этого они хранятся в локальном WebView2 cache.

## Возможности

Локальный помощник может:

- объяснить текущую цепочку;
- объяснить порядок и routing;
- назвать условные и необязательные стадии;
- объяснить оригинальные English Control names;
- предложить безопасные Starting Settings;
- предложить подходящие карточки из локального каталога.

Модель не получает все 365 карточек. Перед каждым вопросом программа выбирает до пяти релевантных карточек и добавляет текущую цепочку. Это уменьшает нагрузку на 4096-token browser context и снижает риск выдуманных сведений.

## Авторитет правил

Порядок приоритетов:

1. детерминированные правила Plugin Navigator;
2. проверенные данные карточек и provenance;
3. curated starting points;
4. практическое объяснение локального ИИ.

ИИ не имеет права отменять предупреждения Помощника порядка.

System prompt требует:

- не выдумывать Controls, диапазоны, URL и официальные функции;
- разделять Product-specific, Product-informed и Family-level;
- не выдавать рекомендацию за официальный manual;
- не представлять все стадии обязательными;
- не утверждать, что модель слышит аудио или видит DAW;
- явно отделять проверенные данные от предположений ИИ.

## Отказоустойчивость

Если WebGPU отсутствует или модель не установлена:

- каталог работает;
- карточки работают;
- готовые цепочки работают;
- конструктор работает;
- Помощник порядка работает;
- пользовательские данные не теряются.

Отключается только локальный ИИ.

## Требования

Практический минимум:

- Windows 10/11 x64;
- Microsoft Edge WebView2 Runtime;
- WebGPU;
- 8 ГБ RAM;
- около 1,5 ГБ свободного места;
- около 2,3 ГБ доступной GPU/shared memory.

Рекомендуется 16 ГБ RAM и актуальный драйвер GPU.

Интернет нужен только для первой загрузки модели и для внешних official links.

## Проверки

Пройдено:

- deterministic HTML build;
- 365 карточек / 99 цепочек / 353 шага;
- AI model ID и WebLLM registry;
- local retrieval exact-product test;
- передача строгой диагностики порядка в AI context;
- guardrail system prompt audit;
- UI fallback без WebGPU;
- JSDOM UI regression;
- embedded Neutralino config;
- побайтовое совпадение HTML;
- наличие embedded WebLLM и AI Worker;
- Windows ZIP integrity;
- общий Download ZIP integrity.

Не пройдено в Arena:

- реальная загрузка 1,1 ГБ модели в Windows WebView2;
- реальный ответ Qwen через Windows WebGPU;
- Playwright layout smoke-test: Chromium CDN оборвал загрузку TLS.

Поэтому перед объявлением аппаратного запуска полностью подтверждённым нужно открыть Windows 2.7.0 на пользовательском компьютере, загрузить модель и задать один тестовый вопрос.
