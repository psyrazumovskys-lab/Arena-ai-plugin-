# Plugin Navigator 2.4.10 — сессия: стол и Clip Gain

## Что изменилось

Новый базовый пункт **«Сессия собрана»** стоит первым.

1. **Порядок дорожек** — имена, ударные → низ → гармония → вокал → FX, цвет по группе.
2. **Рабочий уровень — Clip Gain** — громкость самих клипов, не фейдер и не микс. Кто орёт — вниз, кто пропал — вверх. Ориентир: **−18 dBFS RMS ≈ 0 VU**, не все пики в одну цифру.

**«Прибрать»** теперь два блока: обрезка и Clip Gain *внутри* источника (фразы, ноты). Это не баланс между дорожками.

Порядок урока: собрать → послушать → прибрать → фаза → фейдеры → headroom → референс → mono.

## Что не менялось

Каталог 364, 99 цепей, Controls, описания 2.4.9, иконки, лицензия.

## Сверка

−18 — вход / 0 VU, не картина микса. После рабочего уровня гитары всё ещё могут есть барабаны — это фейдеры.
