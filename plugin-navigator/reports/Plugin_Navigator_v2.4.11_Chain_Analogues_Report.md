# Plugin Navigator 2.4.11 — аналог в цепочке

У каждого звена выпадающий список **Аналог**.

- **Сейчас** — выбранный плагин.
- **То же семейство** — аналоги из карточки.
- **Тот же этап** — другие плагины этой задачи источника.

Где: готовая цепочка в подборе, «Моя цепочка», экспертный конструктор.

Замена обновляет описание и starting settings. Каталог, пресеты и Controls не менялись.
