# Plugin Navigator 2.7.4 — ИИ-панель на всех экранах

**Дата:** 17 октября 2026
**Статус:** реализовано в исходниках, детерминированной сборке HTML и Windows-релизе; живая проверка — на целевой машине.

## Мотивация

ИИ был доступен только в отдельном разделе — чтобы спросить что-то о плагине в каталоге, приходилось переключаться. Теперь ИИ-помощник всегда под рукой: плавающая панель в правом нижнем углу, работающая поверх любой вкладки.

## Что сделано

### Плавающая панель

- кнопка **«✦ ИИ-помощник»** (`ai-fab`) в правом нижнем углу на всех экранах, кроме самого раздела ИИ (там чат уже есть);
- клик открывает панель (`ai-float`, 400px, до 560px высотой, на узких экранах — почти во всю ширину), кнопка «—» сворачивает обратно;
- в панели: индикатор состояния движка + имя модели, чат, быстрые кнопки, поле ввода (Ctrl+Enter), «Отправить»/«Остановить», кнопка «⚙» — переход в полный раздел ИИ (движки, загрузка/удаление моделей);
- состояние «открыта/свёрнута» сохраняется (`pn-ai-panel`);
- история чата общая с полным разделом: `aiRenderMessages` обновляет оба контейнера; `aiSend(fromPanel)` берёт текст из активного поля.

### Контекстная осведомлённость

`aiBuildContext` теперь включает блок **«ТЕКУЩИЙ ЭКРАН ПОЛЬЗОВАТЕЛЯ»**: открытый раздел (человекочитаемое имя), открытая карточка плагина (`state.detail` — целиком передаётся через `aiPluginContext`) и список сравнения (`state.compare`). Быстрые кнопки панели зависят от экрана: на карточке плагина — «Объясни, как пользоваться …», в конструкторе с цепочкой — «Объясни мою текущую цепочку…», иначе — «Составь минимальную цепочку для …».

### Технически

- панель создаётся один раз (`aiPanelInit`) и живёт вне области перерисовки контента;
- `renderContent` обёрнут: после любой перерисовки вызывается `aiPanelSync()` (видимость, статус, быстрые кнопки, disabled-состояния) — панель не ломается при смене вкладок;
- обработчики панели навешиваются один раз (делегирование для быстрых кнопок), сообщения обновляются точечно;
- CSS использует существующие переменные темы (--panel, --line, --blue, --purple, --radius, --shadow); на экранах ≤640px панель растягивается почти на всю ширину.

## Проверки

Пройдено в Arena:

- все замены патча применены единожды (assert в патч-скрипте);
- детерминированная сборка HTML (test_deterministic_build.py);
- полный прогон аудитов: test_user_guide, test_design_audit, test_chain_research_audit, test_plugin_guides, test_local_ai, test_deterministic_build — PASS;
- расширенный test_local_ai.py: маркеры `aiPanelInit`, `aiPanelSync`, `aiPanelQuestion`, `ai-fab`, `ai-float`, `pn-ai-panel`, «ТЕКУЩИЙ ЭКРАН ПОЛЬЗОВАТЕЛЯ», «ОТКРЫТАЯ КАРТОЧКА»;
- Node `--check` script-блока — синтаксис валиден;
- полная Windows-сборка 2.7.4 (verify-windows: PASS).

Не пройдено в Arena (нет живого окружения):

- визуальная проверка панели на реальном экране (позиция, сворачивание, поведение при смене вкладок);
- живой вопрос из панели на открытой карточке плагина.

Чек-лист: открыть каталог → нажать «✦ ИИ-помощник» → убедиться, что панель поверх каталога → открыть карточку плагина → быстрая кнопка «Объясни, как пользоваться…» → свернуть «—» → перезапустить приложение (состояние панели должно сохраниться).
