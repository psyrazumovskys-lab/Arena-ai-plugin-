# Plugin Navigator 2.4.5 — левое меню

## Что изменилось

Левое меню сгруппировано. Длинный список из 33 источников убран из сайдбара — он остаётся на экране «Источники».

### Простой режим

- Главная
- Подготовка: Сессия, Подобрать цепочку
- Каталог: Каталог
- Цепи: Моя цепочка, Мои цепочки
- Ещё: Словарь, Избранное

### Экспертный режим

- Главная
- Подготовка: Сессия, Подбор
- Каталог: Плагины, Источники, Семейства
- Цепи: Конструктор, Presets, Мои цепочки
- Ещё: Словарь, Избранное, Сравнение, Что сделать

Нижняя мобильная панель из 5 пунктов не менялась. Каталог, цепочки и Controls не трогались.
