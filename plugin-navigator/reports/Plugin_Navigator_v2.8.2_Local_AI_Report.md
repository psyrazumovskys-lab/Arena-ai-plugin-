# Plugin Navigator 2.8.2 — ИИ предлагает плагины без вопроса об источнике

**Дата:** 18 октября 2026
**Статус:** реализовано в исходниках, детерминированной сборке HTML и Windows-релизе; живая проверка — на целевой машине.

## Мотивация

Пользователь попросил у ИИ «какой-нибудь эквалайзер, эмулятор аналогового». Вместо вариантов ИИ сначала потребовал выбрать источник. Пользователь ожидает другое: вопрос про плагин должен сразу получать варианты.

## Диагноз

Контекст формировался правильно: на слово «эквалайзер» срабатывает категорийный контекст (aiCategoryContext отдаёт всю категорию «EQ и тон» — 5 семейств, включая аналоговые эмуляции API, Neve, Pultec). Модель блокировала системный промпт: правило 8 (цепочки) требует источник перед составлением цепочки, а отдельного правила для подбора плагинов не было — 2B-модель трактовала любой запрос как цепочечный и переспрашивала.

## Что сделано

В системный промпт добавлено правило 12 «ПОДБОР ПЛАГИНОВ БЕЗ ЦЕПОЧКИ»:

- просьба «дай какой-нибудь эквалайзер», «посоветуй аналог», «нужен эмулятор аналогового», «что выбрать для…» — НЕ запрос цепочки: не спрашивать источник, не требовать уточнений;
- сразу 2–4 конкретных плагина из ЛОКАЛЬНОГО КОНТЕКСТА (ПОДХОДЯЩИЕ КАРТОЧКИ / ВСЕ ПЛАГИНЫ КАТЕГОРИИ): имя, семейство, чем отличается, для какой задачи лучше;
- если подходящие плагины есть в списке «ПЛАГИНЫ ПОЛЬЗОВАТЕЛЯ» — начинать с них (согласовано с правилом 11);
- блок ДЕЙСТВИЕ — только при явной просьбе собрать/изменить цепочку.

Правила 8–11 не менялись: цепочка по-прежнему требует источник и подтверждение. В инструкцию добавлен подраздел «Совет по плагину — сразу варианты»; заодно актуализирована устаревшая строка о версии Windows-приложения в разделе про ИИ.

- детерминированная сборка HTML; полный прогон 6 аудитов — PASS;
- расширенный test_local_ai.py: маркеры «ПОДБОР ПЛАГИНОВ БЕЗ ЦЕПОЧКИ», «не спрашивай источник»;
